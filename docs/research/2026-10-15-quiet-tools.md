# Portfolyo için sessiz fayda sağlayabilecek küçük araçlar

Araştırma tarihi: 2026-10-15. GitHub yıldız/lisans/push alanları GitHub REST repo metadatasından alındı; README ve gereken kaynak dosyalar GitHub connector ile okundu. Yıldız sayıları anlık değişebilir. Paketler projeye kurulmadı veya çalıştırılmadı.

## Mevcut siteye göre kısa karar

Portfolyo içindeki README.md, brand.md, docs/design.md ve src/layouts/Layout.astro incelendi. Site Astro + TypeScript + StyleX; sistem temasına bağlı siyah/beyaz, geniş boşluk, küçük JS bütçesi ve tek motto çizgisinde. Yerel başlık/açıklama araması zaten native dialog içinde Ctrl/⌘K ile çalışıyor; Home, Donate, RSS, PGP, TOR, I2P sayfalarını tarayıcıda görünen veriden filtreliyor ve ağa istek atmıyor. RSS route’u ve keşif bağlantısı zaten var, ancak gerçek yazılar yok. README özellikle boş projeler/notlar sayfası açılmadığını ve RSS’in gerçek yayın başlayana kadar boş tutulduğunu söylüyor.

Bu nedenle en kuvvetli eklemeler yeni kütüphaneler değil, gerçek içerik bulunduğunda açılacak küçük statik yüzeyler:

1. **/now**: Şu sıralar ne üzerinde çalıştığını birkaç kısa paragrafla belirten, güncelleme tarihli tek sayfa. Bir Content Collection girdisinden statik HTML üret; sayfada tek H1, kısa metin, düz tarih olsun. Yeni mottolar, zaman çizelgesi kartları veya sürekli güncelleme vaadi ekleme. Sayfa yalnızca gerçek ve güncel bilgi olduğunda açılsın.
2. **/uses**: Kullanılan araçları/ekipmanı yalnızca başkasının karar vermesine yarayacak kadar seçip, kısa gerekçeleriyle listele. Affiliate/alışveriş CTA’sı ekleme. Mevcut siyah-beyaz tipografik satırlar bu içeriğe yeter; donanım listesi henüz anlamlı değilse açmamak daha iyi.
3. **Proje laboratuvarı / proje kayıtları**: README şu an proje olmadığını açıkça belirtiyor. İlk gerçek, gösterilebilir proje olduğunda Content Collection’da doğrulanmış metadata (durum, kısa özet, kaynak kodu/demo bağlantıları ve varsa teknik kararlar) ile statik liste ve yalnızca değeri olan detay sayfası üret. Önerdiğim **default-deny yayın kapısı** ANC’nin mevcut davranışı değil; bu portfolyonun mahremiyet tonu için kendi uyarlamamız: proje varsayılan olarak yayınlanmasın, açık published: true işareti olmadan üretim build’ine girmesin. ANC’den alınabilecek fikir; release öncesi kesin yayın kümesini gözden geçirme ve katı içerik şemasıyla build’i doğrulama. Yanlış/bozuk yayın kuralı build’i durdursun. İlk projeler geldiğinde arama mevcut yerel aramaya katılabilir.
4. **RSS**: Zaten /rss.xml ve header’da alternate feed var. İçerik oluştuğunda gerçek yayın girdilerini buraya bağlamak yeterli; sırf RSS’e format eklemek için Atom/JSON endpoint açmaya gerek yok. Feed içeriğinin siteye gitmeden okunması istenirse tam içerik mi özet mi olacağı editoryal karar olmalı.
5. **Tipografi / komut arayüzü**: Yeni bir palet açmak gereksiz; mevcut arama Ctrl/⌘K. Aramaya gerçek proje/yazı başlıkları katılınca doğal olarak daha faydalı olur. Mevcut search kodunu geliştirmek gerekirse önce küçük bir klavye kullanılabilirliği düzeltmesi seç; ikinci modal, animasyon veya tema kontrolü ekleme.

## Repo kaynakları ve ölçüm yöntemi

Metadata alanları 2026-10-15’te https://api.github.com/repos/{owner}/{repo} üzerinden okundu (stars, license.spdx_id, pushed_at); README/kaynaklar GitHub connector ile varsayılan branch’ten alındı. Favo02 reposunda GitHub API lisans alanı boş döndü. anc ve Favo02/favo02.dev 0★ olduğu için yıldız üst sınırına uyuyor, ancak yıldız sayısı kalite garantisi sayılmaz. Repo değerlendirmeleri kod örneklerinin proje uyumuna dair çıkarımdır; yerel entegrasyon veya bakım devamlılığı garantisi değildir.

## Son öneri

En güçlü üç fikir: gerçek bilgi varsa /now; ilk yayınlanabilir proje olduğunda statik bir proje kaydı; bu portfolyo için benim önerdiğim default-deny yayın kapısı. ANC’nin katkısı default-publish yaklaşımı değil, katı şema/release review ve yayın kümesinin denetlenmesi; README’de withheld bağlantı etiket/yolu metadata sızıntısı riski de açıkça tarif ediliyor. /uses içeriğe bağlı, RSS ve arama ise mevcut altyapı üzerinden büyütülebilir. Dört kütüphaneden hiçbiri şu anda projeye eklenmesi gereken bir bağımlılık değil.
