# SVG sources

- `rss.svg`: existing portfolio RSS glyph extracted from the layout; loaded as a local image.
- `search-home.svg`, `search-donate.svg`, `search-key.svg`: original outline glyphs authored for this portfolio's search results; loaded as local images.

- `onur.svg`: owner-supplied `/home/yargc/Downloads/logo (4).svg`, unchanged.
- `icon.png`, `apple-touch-icon.png`: raster versions of `onur.svg`, pure white mark on black; icon 512 × 512, touch icon 180 × 180.
- `social.png`: 1200 × 630 fallback homepage card, generated by `src/portfolio/social-image.ts` with the same logo, motto, page title and description as the dynamic cards.
- `/favicon.ico`: 16/32/48px raster variants of the same mark for favicon consumers.
- `tor.svg`: Tor Project onion glyph, https://styleguide.torproject.org/static/images/tor-browser/glyph/glyph.svg ; displayed in white on dark background. Source: https://styleguide.torproject.org/brand-assets/ .
- `i2p.svg`: user-selected I2P logo 2019, https://upload.wikimedia.org/wikipedia/commons/4/4e/I2P_logo_2019.svg ; source and public-domain designation: https://tr.wikipedia.org/wiki/Dosya:I2P_logo_2019.svg . Original vector preserved, displayed white with CSS.

Site typography: system sans-serif. Social cards bundle Liberation Sans regular and bold under the license in `src/portfolio/fonts/LICENSE`; the renderer does not depend on fonts installed on the deployment host. Bleed theme removed at owner request.
