# SVG sources

- `rss.svg`: existing portfolio RSS glyph extracted from the layout; loaded as a local image.
- `search.svg`: original magnifying-glass outline glyph authored for this portfolio; loaded as a local image.
- `search-home.svg`, `search-donate.svg`, `search-key.svg`: original outline glyphs authored for this portfolio's search results; loaded as local images.

- `onur.svg`: owner-supplied `/home/yargc/Downloads/logo (4).svg`, unchanged.
- `icon.png`, `apple-touch-icon.png`: raster versions of `onur.svg`, pure white mark on black; icon 512 × 512, touch icon 180 × 180.
- `social.png`: 1200 × 630 fallback homepage card, generated by `src/portfolio/social-image.ts` with the same logo and selected motto as the dynamic homepage cards.
- `/favicon.ico`: 16/32/48px raster variants of the same mark for favicon consumers.
- `tor.svg`: Tor Project onion glyph, https://styleguide.torproject.org/static/images/tor-browser/glyph/glyph.svg ; displayed in white on dark background. Source: https://styleguide.torproject.org/brand-assets/ .
- `i2p.svg`: user-selected I2P logo 2019, https://upload.wikimedia.org/wikipedia/commons/4/4e/I2P_logo_2019.svg ; source and public-domain designation: https://tr.wikipedia.org/wiki/Dosya:I2P_logo_2019.svg . Original vector preserved, displayed white with CSS.

Site typography: system sans-serif. Social cards bundle Liberation Sans regular and bold under the license in `src/portfolio/fonts/LICENSE`; the renderer does not depend on fonts installed on the deployment host. Bleed theme removed at owner request.

- `x.svg`, `github.svg`, `rust.svg`, `typescript.svg`, `javascript.svg`: Simple Icons SVG paths from https://github.com/simple-icons/simple-icons/tree/develop/icons (CC0). Original paths and viewboxes preserved; title elements removed for decorative use and fill set to white. Shared theme filtering follows the site icon standard.

- `spotify.svg`: Simple Icons Spotify mark from https://github.com/simple-icons/simple-icons/blob/develop/icons/spotify.svg (CC0); original paths preserved with white fill and decorative title removed.

- `chevron-down.svg`: original 16 px white outline chevron authored for the native Spotify Recent disclosure; rendered through the common icon registry.

- `heart.svg`, `repost.svg`: original 16 px white outline glyphs authored for native post counters; rendered through the common icon registry.

- `proof.svg`: original monochrome 16 px identity-proof check authored for this portfolio.

- `discord.svg`, `reddit.svg`, `telegram.svg`: Simple Icons (https://github.com/simple-icons/simple-icons), CC0, white monochrome variants.
- `share.svg`, `share-link.svg`, `share-mail.svg`: original portfolio interface artwork, white monochrome.

- `share-mark.svg`: original portfolio artwork; three linked diamond nodes, white monochrome.
- `xmpp.svg`: XMPP Foundation & Nicola Spanti, user-selected black XMPP logo from https://commons.wikimedia.org/wiki/File:Xmpp-logo-dark.svg ; original SVG and viewBox preserved. MIT/Expat license, copyright XMPP Standards Foundation; see `xmpp-LICENSE.txt`. Shared CSS handles monochrome theme rendering.
- `connect-mail.svg`: Tabler Icons `mail-fast`, https://github.com/tabler/tabler-icons/blob/main/icons/outline/mail-fast.svg ; MIT, copyright Paweł Kuna. Original paths and 24 × 24 viewBox preserved; stroke set to white for shared theme rendering. License: `tabler-LICENSE.txt`. The Share dialog retains its own mail icon.
